Sorting Composite Quantile Regression Neural Network (SCQRNN) implemented in PyTorch.


### 1. Clone the repository

```bash
git clone https://github.com/RektPunk/scqrnn.git
cd scqrnn
```

### 2. Install dependencies

```bash
uv sync
```

### 3. Run the examples

```bash
uv run main.py
```
